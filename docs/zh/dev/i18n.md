# 前端国际化（i18n）

前端使用 [vue-i18n](https://vue-i18n.intlify.dev/) 提供中英日三语界面，Element Plus 的内置文案会随语言一起切换。

## 目录结构

```
web/src/i18n/
├── index.ts                 # createI18n、语言检测、切换入口
└── locales/
    ├── zh-CN/
    │   ├── common.ts        # 通用文案（导航、路由标题、操作、错误等）
    │   ├── index.ts         # 汇总 common 与 views 下的模块
    │   └── views/*.ts       # 按页面/功能拆分的文案
    ├── en-US/
    │   └── ...              # 与 zh-CN 完全对应的键树
    └── ja-JP/
        └── ...              # 与 en-US 完全对应的键树
```

`views/*.ts` 通过 `import.meta.glob` 自动加载，新增模块文件后无需修改汇总入口。

语言偏好保存在 `localStorage` 的 `axmipic.locale.v1`；首次访问时按浏览器语言推断：
中文环境使用 `zh-CN`，日文环境使用 `ja-JP`，其余使用 `en-US`。控制台顶栏与公开页面的悬浮按钮都可以切换语言。

## 在组件中使用

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t } = useI18n()
</script>

<template>
  <el-button :title="t('common.refresh')">{{ t('common.save') }}</el-button>
  <p>{{ t('users.selection.count', { count: selected.length }) }}</p>
</template>
```

- 模板属性使用绑定：`:label`、`:placeholder`、`:title`、`:aria-label`、`:empty-text`。
- 插值统一使用 `{name}`，调用时传入对象，不要用字符串拼接。
- `ElMessage`、`ElMessageBox`、表单校验规则中的文案也要走 `t()`。
- 非 setup 上下文（store、工具函数、API client）使用 `translate('key')`。
- 模块级常量数组中的中文不会随语言切换更新，应放入 `computed(() => [...])` 或在模板中渲染 `t(item.labelKey)`。

## 新增文案

1. 在 `zh-CN/views/<module>.ts`、`en-US/views/<module>.ts` 与 `ja-JP/views/<module>.ts` 中添加同名键；三套键树必须完全一致。
2. 中文保持用户可见的原文，英文与日文使用简洁自然的表达。
3. 语言切换后仍需更新的动态标签请使用 `computed`。
4. 不要翻译用户数据、API 路径、枚举值、配置键、存储驱动标识与 URL。

## 注意事项

- **`@` 需要转义**：vue-i18n 会把 `@` 当作链接消息语法。文案中需要显示 `@` 时写成 `{'@'}`，例如 `you{\'@\'}example.com`（单引号字符串内需转义）。
- **`|` 表示复数**：普通文案不要出现裸 `|`。
- 文案中如出现字面量 `{` 或 `}`，同样需要按 vue-i18n 语法转义。
- 切换语言会同步更新 `<html lang>`、页面标题与 `meta[name="description"]`；已经取回并缓存的**服务端错误信息**不会自动翻译，重新请求后会使用新语言的前端兜底文案。
- Element Plus 语言包在 `App.vue` 的 `el-config-provider` 中按当前语言注入，新增语言时需同时补充对应的 Element Plus locale。

## 新增语言

1. 在 `src/i18n/locales/` 下新建语言目录并复制完整键树。
2. 在 `src/i18n/index.ts` 的 `SUPPORTED_LOCALES`、`LOCALE_OPTIONS` 与 `messages` 中注册。
3. 在 `App.vue` 中补充 Element Plus 语言包映射。
4. 运行 `pnpm typecheck` 与 `pnpm build`，并检查所有 `t()` 键在三种语言中都存在。

## 校验

```bash
cd web
pnpm typecheck   # 类型检查
pnpm build       # 构建内嵌产物
```

提交前建议用以下命令确认没有遗漏的用户可见中文（注释除外）：

```bash
grep -rnP '[\x{4e00}-\x{9fa5}]' src --include=*.vue --include=*.ts | grep -v 'src/i18n/locales'
```
