# はじめに

軽量で信頼性の高いセルフホスト型画像ホスティングサービスです。画像のアップロード、オンザフライ処理、複数のストレージバックエンド、管理者コンソールを提供します。バックエンドは単一の Go バイナリで、フロントエンドは埋め込みのシングルページアプリケーションです。

## 機能

- **複数のアップロード方法**: 管理者 UI からのアップロード、バッチアップロード、貼り付けアップロード、ドラッグ＆ドロップアップロード、`multipart` API アップロード、オブジェクトストレージへの署名付き直接アップロード
- **ワンクリックの埋め込みコード**: 画像の URL、HTML、BBCode、Markdown をコピーできます（ロールの機能トグルで制御）
- **画像とアルバムの共有**: アクセスパスワード、有効期限、最大訪問回数を任意に設定した共有リンクを生成できます。公開共有ページは `/s/{token}` です
- **お知らせと単独ページ**: 管理者はダッシュボードに表示されるお知らせ（ピン留めと重要度レベル付き）を公開でき、`/p/{slug}` で一般公開される単独ページも維持できます
- **通報管理**: ユーザーが画像を通報し、管理者が管理者コンソールで通報を処理または却下します
- **プランと課金**: プラン（価格、有効期間、クォータ、ロールグループ）とクーポン（固定額/割合、しきい値、利用回数上限、有効期間）、さらにチェックアウト、注文管理、プラグイン可能な決済チャネル
- **ファーストパーティ決済連携**: Alipay 対面決済（RSA2 署名/検証）と WeChat Pay v3（SHA256-RSA 署名、AES-GCM によるコールバック復号）、および手動/モックチャネル
- **画像の安全性**: プラグイン可能なアップロードコンテンツスキャナ（ホワイトリストと危険なマジックナンバー検出を標準搭載）により、画像に偽装した実行可能コンテンツを拒否します
- **通知システム**: プラグイン可能な SMS（汎用 HTTP ゲートウェイ）とメール（SMTP/STARTTLS）チャネルに対応し、管理者コンソールからテスト送信できます
- **チケットシステム**: ユーザーがチケットを送信してサポートに連絡し、管理者が返信・クローズします
- **ランダムなストレージキーと重複排除**: 保存ファイルは日付で分割されたランダムで推測不可能なキー名を使用します。コンテンツの `sha256` は別途記録されるため、同一オーナーが同一コンテンツをアップロードした場合は自動的に重複排除され、異なるオーナーの場合はそれぞれ独立したオブジェクトを保持します
- **元のファイル名を保持**: ストレージ層はランダムな名前のファイルを使用し、データベースには元のファイル名、保存ファイル名、ハッシュを別途記録します
- **複数の画像処理ドライバー**: 純粋な Go（デフォルト）、libvips（`-tags libvips`）、ImageMagick（`magick` コマンド）のプロセッサを実行時の設定で選択でき、利用できない場合はフォールバックします
- **オンザフライの画像処理**: URL クエリパラメータによるリアルタイムのリサイズ、トリミング、回転、反転、グレースケール、ぼかし、シャープ化、テキスト透かし、フォーマット変換を、ETag キャッシュ付きで提供します
- **複数のストレージバックエンド**: ローカルファイルシステム、S3 互換オブジェクトストレージ（AWS S3 / MinIO / Cloudflare R2）、Alibaba Cloud OSS、Tencent Cloud COS、Qiniu Cloud Kodo
- **実行中のストレージ切り替え**: デフォルトストレージは管理者コンソールからいつでも切り替えられます。既存の画像は記録に基づいて読み取り時に自動的に元のストレージへ振り分けられるため、再起動は不要です
- **オプションのデータベース**: SQLite（デフォルト、そのまま動作）または PostgreSQL
- **アルバムと画像広場**: 画像をアルバムに整理できます。画像とアルバムの両方を公開でき、ユーザー横断の画像広場と公開アルバム一覧に表示され、公開ユーザープロフィールページも利用できます
- **ロールグループと複数ポリシー**: ロールグループはユーザーのストレージクォータ、アップロード上限、レート制限、画像処理機能、機能トグルを制御します。ポリシーは再利用可能で種類ごとに上書きでき、新規登録ユーザーは自動的にデフォルトのロールグループに参加します
- **アカウントシステム**: 管理者と一般ユーザーは別々のテーブルで管理されます。JWT セッション + 長期有効な API トークン
- **分離されたインターフェースとセットアップモード**: 公開ランディングページ + ユーザーセンター（`/user`）と管理者コンソール（`/admin`）を分離。低権限の Guest ビジターを標準搭載し、`/install` で手動で入るセットアップモードも用意しています
- **クォータとレート制限**: ユーザーごとのストレージクォータ、およびユーザー/ゲスト/IP ごとのレート制限
- **セキュリティ**: AES-256-GCM による保存時のシークレット暗号化、bcrypt パスワード、多層防御のレスポンスヘッダー

## 技術スタック

| レイヤー | 技術 |
|-------|------------|
| バックエンド | Go 1.26、chi ルーター、GORM |
| データベース | SQLite（純粋な Go ドライバー）/ PostgreSQL |
| 画像処理 | 純粋な Go（`disintegration/imaging`）、オプションで libvips（`-tags libvips`） |
| オブジェクトストレージ | ローカル / S3 互換（minio-go）/ Alibaba Cloud OSS SDK / Tencent Cloud COS SDK / Qiniu SDK |
| 決済 | 公式 WeChat Pay SDK（`wechatpay-apiv3/wechatpay-go`）、Alipay RSA2（ネイティブ）、YiPay（ネイティブ） |
| フロントエンド | Vue 3、Pinia、Vue Router、Element Plus、TypeScript、Vite |
