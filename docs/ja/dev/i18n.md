# フロントエンドの国際化（i18n）

フロントエンドは [vue-i18n](https://vue-i18n.intlify.dev/) を使用して中国語・英語・日本語のインターフェースを提供しており、Element Plus の組み込みテキストも言語に合わせて切り替わります。

## ディレクトリ構造

```
web/src/i18n/
├── index.ts                 # createI18n、ロケール検出、切り替えのエントリーポイント
└── locales/
    ├── zh-CN/
    │   ├── common.ts        # 共有文字列（ナビゲーション、ルートタイトル、アクション、エラーなど）
    │   ├── index.ts         # common と views 配下のモジュールを集約
    │   └── views/*.ts       # ページ/機能ごとに分割した文字列
    ├── en-US/
    │   └── ...              # zh-CN を完全にミラーしたキーツリー
    └── ja-JP/
        └── ...              # zh-CN を完全にミラーしたキーツリー
```

`views/*.ts` ファイルは `import.meta.glob` によって自動的に読み込まれるため、モジュールファイルを追加しても集約エントリーポイントを変更する必要はありません。有効なロケールは `zh-CN`、`en-US`、`ja-JP` の 3 つです。

言語設定は `localStorage` の `axmipic.locale.v1` に保存されます。初回訪問時にはブラウザの言語から推測されます。
中国語環境では `zh-CN`、日本語環境では `ja-JP`、それ以外は `en-US` が使用されます。保存済みの設定がある場合はそれが優先され、
フォールバックロケールは `zh-CN` です。言語は管理コンソールのトップバーからも、公開ページのフローティングボタンからも切り替えられます。

## コンポーネントでの使用

```vue
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { t } = useI18n()
</script>

<template>
  <el-button :title="t('common.refresh')">{{ t('common.save') }}</el-button>
  <p>{{ t('users.selection.count', { count: selected.length }) }}</p>
</template>
```

- テンプレートの属性にはバインディングを使用します: `:label`、`:placeholder`、`:title`、`:aria-label`、`:empty-text`。
- 補間には常に `{name}` を使用し、文字列を連結するのではなく呼び出し側でオブジェクトを渡します。
- `ElMessage`、`ElMessageBox`、フォームバリデーションルール内の文字列も `t()` を経由する必要があります。
- setup コンテキストの外（ストア、ユーティリティ関数、API クライアント）では `translate('key')` を使用します。
- モジュールレベルの定数配列内の中国語テキストは、言語を切り替えても更新されません。`computed(() => [...])` に入れるか、テンプレートで `t(item.labelKey)` をレンダリングしてください。

## 新しい文字列の追加

1. `zh-CN/views/<module>.ts`、`en-US/views/<module>.ts`、`ja-JP/views/<module>.ts` に同じキーを追加します。キーツリーは完全に一致している必要があります。
2. ユーザーに表示される原文は中国語のまま維持し、英語版と日本語版には簡潔で自然な表現を使用します。
3. 言語切り替え後も更新される必要がある動的ラベルには `computed` を使用します。
4. ユーザーデータ、API パス、列挙値、設定キー、ストレージドライバー識別子、URL は翻訳しないでください。

## 注意事項

- **`@` はエスケープが必要です**: vue-i18n は `@` をリンクメッセージ構文として扱います。リテラルの `@` を表示するには `{'@'}` と記述します。例: `you{\'@\'}example.com`（シングルクォート文字列ではエスケープが必要です）。
- **`|` は複数形を意味します**: 通常の文字列で裸の `|` を使用しないでください。
- 文字列内のリテラルの `{` や `}` も、同様に vue-i18n の構文に従ってエスケープする必要があります。
- 言語を切り替えると `<html lang>`、ページタイトル、`meta[name="description"]` も更新されます。すでに取得してキャッシュされた**サーバーエラーメッセージ**は自動翻訳されません。再リクエストすると、新しい言語のフロントエンドフォールバックテキストが使用されます。
- Element Plus のロケールパックは、`App.vue` の `el-config-provider` で現在の言語に応じて注入されます。`zh-CN` には `zh-cn`、`en-US` には `en`、`ja-JP` には `ja` が対応します。言語を追加するときは、対応する Element Plus ロケールも追加する必要があります。

## 言語の追加

1. `src/i18n/locales/` の下に新しいロケールディレクトリを作成し、完全なキーツリーをコピーします。既存の 3 ロケール（`zh-CN`、`en-US`、`ja-JP`）は同じ構造を共有しているため、いずれかをテンプレートとして使用できます。
2. `src/i18n/index.ts` の `SUPPORTED_LOCALES`、`LOCALE_OPTIONS`、`messages` に登録します。ブラウザ言語からの推測も、必要に応じて `detectLocale` に追加します。
3. `App.vue` に Element Plus のロケールマッピングを追加します。
4. `pnpm typecheck` と `pnpm build` を実行し、すべての `t()` キーが 3 言語すべてに存在することを確認します。

## 検証

```bash
cd web
pnpm typecheck   # 型チェック
pnpm build       # 埋め込みアーティファクトをビルド
```

コミット前に、次のコマンドで翻訳漏れのユーザー向け中国語（コメントを除く）がないことを確認することをお勧めします:

```bash
grep -rnP '[\x{4e00}-\x{9fa5}]' src --include=*.vue --include=*.ts | grep -v 'src/i18n/locales'
```
