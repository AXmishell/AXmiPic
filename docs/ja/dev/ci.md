# 継続的インテグレーション

リポジトリには次の GitHub Actions ワークフローが含まれています:

- `.github/workflows/ci.yml`: バックエンドの `go mod tidy` による整合性チェック、`gofmt`、`go vet`、`staticcheck`、ビルド、レーステストを実行し、フロントエンドの型チェックとビルドを実行したうえで、両方のエンドツーエンドビルドを行います。
- `.github/workflows/docker.yml`: マルチアーキテクチャのコンテナイメージをビルドして GHCR にプッシュします（プルリクエストではビルドのみで、プッシュは行いません）。
- `.github/workflows/release.yml`: `v*` タグがプッシュされたとき（または手動でタグが指定されたとき）に、複数プラットフォーム向けのバイナリをクロスコンパイルして GitHub Release を作成します。リリースノートは、そのタグと前回のタグの間のコミットメッセージから生成されます（最初のリリースでは、そのタグのコミットメッセージから生成されます）。
