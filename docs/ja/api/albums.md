# アルバムと画像広場

| メソッド | パス | 説明 |
|--------|------|-------------|
| GET | `/albums` | 現在のアカウントのアルバム(画像数、所有者、公開範囲を含む) |
| POST | `/albums` | アルバムを作成します(任意で `permission`: `private`/`public` を指定) |
| GET | `/albums/{id}` | アルバムの詳細(公開アルバムはログイン不要) |
| PATCH | `/albums/{id}` | アルバムの名前/説明/公開範囲を変更します(所有者のみ) |
| DELETE | `/albums/{id}` | アルバムを削除します(画像は保持され、アルバムから外れるだけです) |
| GET | `/albums/{id}/images` | アルバム内の画像(公開アルバムはログイン不要) |
| GET | `/plaza` | 公開画像広場(ユーザー横断。`permission=public` の画像を返し、`user_id` によるアップロード者の絞り込みに対応) |
| GET | `/plaza/albums` | 公開アルバム一覧(`user_id` による絞り込みに対応) |
| GET | `/users/{id}` | 公開ユーザープロフィール: ユーザー名、公開画像数、公開アルバム |

画像の `permission` は `private`(デフォルト。所有者のみ表示)または `public`(画像広場に表示される可能性があり、公開一覧には `owner_username` が含まれます)のいずれかです。アルバムの `permission` も同様に `private`(デフォルト)または `public` です。公開アルバムの詳細と画像は未認証の訪問者にも公開され、`/plaza/albums` に表示されます。画像広場、公開アルバム、ユーザープロフィールは読み取り専用のエンドポイントで、サインインせずにアクセスできます。
