# 画像セキュリティ、クラウド処理、SMS、メール

これらの機能はすべてプラグイン可能なインターフェースを通じて実装されています。プロバイダーが設定されていない場合は、安全なデフォルト実装にフォールバックします。

| 設定 | 説明 |
|---------|-------------|
| `security.scanner` | アップロードコンテンツスキャナ: `none`(許可)または `builtin`(許可リスト + 危険なマジックナンバー検出。画像に偽装した実行可能コンテンツを拒否します) |
| `security.cloud_processor` | クラウドプロセッサ: `local`(組み込みの画像処理パイプラインを使用)。外部クラウドサービスを統合するには `security.CloudProcessor` を実装します |
| `sms.*` | 汎用 HTTP SMS ゲートウェイ: `enabled`、`provider`、`endpoint`、`method`。有効でない場合、メッセージはログに書き込まれます |
| `email.*` | SMTP メール: `host`、`port`、`username`、`password`、`from`、`use_tls`。有効でない場合、メッセージはログに書き込まれます |

管理エンドポイント:

| メソッド | パス | 説明 |
|--------|------|-------------|
| GET | `/admin/security` | 現在有効なスキャナ |
| GET | `/admin/runtime` | インスタンスの実行環境情報(サイトアドレス、データベース/ストレージ/プロセッサ、クォータとレート制限など。シークレットは含みません) |
| GET | `/admin/process` | 実行中プロセスのランタイムメトリクス(goroutine、ヒープメモリ、ヒープオブジェクト数、GC、稼働時間など) |
| GET | `/admin/notify/channels` | 設定済みの SMS およびメールチャネル |
| POST | `/admin/notify/test` | テスト通知を送信します(`{"channel":"sms","to":"…","body":"…"}`) |
| GET | `/admin/notify/logs` | 通知送信ログ(`?channel=email\|sms&page=&page_size=`。新しい順) |
| GET | `/admin/notify/smtp` | SMTP メールチャネル設定を読み取ります(パスワードは設定済みかどうかのみを返します) |
| PUT | `/admin/notify/smtp` | SMTP 設定を保存し、即時反映します(空の `password` は既存のパスワードを維持することを意味します) |
| GET/PUT | `/admin/auth` | 権限トグルをオンラインで読み取り/切り替えます(`allow_registration`、`require_auth`、`allow_guest_upload`)。保存は再起動なしで即時反映されます |
| GET/PUT | `/admin/moderation` | 画像広場の AI モデレーション設定をオンラインで読み取り/保存します(シークレットはマスクされます)。保存は再起動なしで即時反映されます |
| GET | `/admin/payment` | 決済設定を読み取ります(シークレットは設定済みかどうかのみを返します) |
| PUT | `/admin/payment` | 決済設定を保存し、即時反映します(空のシークレットは既存の値を維持することを意味します) |

スキャナは 2 つのエントリーポイントで実行されます: `multipart` アップロードと署名付き直接アップロードの確認です。危険なコンテンツが検出されると HTTP 422 を返し、オブジェクトの保存を拒否します。通知チャネルのフォールバック実装はメッセージをサーバーログに書き込むため、開発やデバッグに役立ちます。管理者コンソールの「システム設定 → 通知設定」では、SMTP 設定、チャネルの確認、テスト送信を利用できます。SMTP パスワードはマスターキーで暗号化されてデータベースの `settings` テーブルに保存され、保存後は再起動なしでメールチャネルが即座に切り替わります。すべての送信(認証コード、通知、管理者のテストメッセージを含む)は `notify_logs` テーブルに記録され、管理者サイドバーの「メールログ」ページでメール/SMS 別に確認できます。ログは 30 日間保持された後、自動的に削除されます。
